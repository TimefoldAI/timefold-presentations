Who builds what

You build

The app: website, mobile app, agent workflow, chatbot. Any language works.

Timefold plans

The planning model: ready-made, or your own.

You bring

Realistic data: made-up but believable, at real-problem size.

Your data goes in.
The best plan comes out.

  1. You describe the problem as JSON: what, to whom, which rules
  2. Timefold searches: tries many plans, scores each, keeps the best
  3. You get the plan back with a score, like 0hard/-12soft

Hard vs. soft

  • HARD Never break. 0hard means every one holds.
  • SOFT Preferences. Closer to 0soft is better.

Teams of two to five

Arriving alone is normal: most people do

How teams form

  1. At the briefing, pitch your problem in one or two sentences
  2. People join the problem they care about most
  3. Organizers balance teams that are too big or too small
  4. Every team gets a problem, a name, and a table

Rules

Every project needs these to be judged

What every project needs

  1. Help people locally: a real planning problem in a local community
  2. Teams of two to five, formed on the day
  3. Use Timefold for the planning: ready-made or your own
  4. AI agents are welcome, but you must understand your code

And

  1. Open tools and data are fine. Credit them.
  2. No real personal data. Names, addresses, health details: made-up or anonymized only.
  3. Follow the code of conduct and privacy policy of The AI Collective.

Breaking the rules can mean disqualification. Teams get a chance to explain first.

Option B: build your own

MCP server, license key, then a quickstart

Step 1: JDK 21 or higher and Maven

# macOS
brew install --cask temurin@21
brew install maven
# Windows
winget install EclipseAdoptium.Temurin.21.JDK
winget install Apache.Maven
# Ubuntu / Debian
sudo apt install openjdk-21-jdk maven
# Any OS, with SDKMAN
sdk install java <21.x-tem identifier from: sdk list java>
sdk install maven

java -version   # openjdk version "21.0.x" or higher
mvn -version    # Apache Maven 3.9.x, running on Java 21+

Step 2: connect the MCP server

Copy the server URL from prd.timefold.ai

# Claude Code
claude mcp add --transport http timefold-prd <MCP_SERVER_URL>

# Codex: ~/.codex/config.toml
[mcp_servers.timefold-prd]
url = "<MCP_SERVER_URL>"

Check: ask your agent "Which tools does the timefold-prd MCP server give you?"

Step 3: the license key

Download the hackathon license: timefold-license.pem

# Easiest: put it in your home directory
mv ~/Downloads/timefold-license.pem ~/timefold-license.pem

# Or point an environment variable at it
export TIMEFOLD_LICENSE_PATH=/absolute/path/to/timefold-license.pem
export TIMEFOLD_LICENSE="$(cat ./path/to/timefold-license.pem)"

Keep the name timefold-license.pem exactly, and don't commit it to your repository.

Step 4: start from a quickstart

  • People assigned to shifts → Employee scheduling
  • Drivers visiting stops → Vehicle routing
  • Sessions in a room and slot → School timetabling or Meeting scheduling
git clone https://github.com/TimefoldAI/timefold-quickstarts.git
cd timefold-quickstarts/java/employee-scheduling
mvn quarkus:dev   # open http://localhost:8080

No written submission

Your five-minute live demo is your entry

Half the score is the panel.
Half is the room.

Judges panel

50%

Four weighted criteria, scored one to five

Audience vote

50%

Each team ranks its top three. Not your own.

Judges panel criteria

  • 30% Community impact: a real, local problem; clear who benefits
  • 30% Modeling the problem: sensible hard and soft constraints, feasible plan
  • 20% Working solution: model and app work end to end, live, on realistic data
  • 20% Demo: problem, solution and result clear in five minutes

Custom models can score highest on modeling

A well-configured ready-made model (A) can reach a three or four.

A five needs custom constraints for your community's specific rules (B), and a trade-off the model made that you can explain.

Audience vote

After the last demo, agree as a team on the three projects you'd most like to see used in your own community.

  • First choice: 3 points
  • Second choice: 2 points
  • Third choice: 1 point

Ties: more judges points wins, then higher community impact.
